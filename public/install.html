Catarse no seu dispositivo.

O mesmo painel, com seus dados sincronizados. Conexão com a internet necessária.

Mac

Instalador para Intel e Apple Silicon. Arraste o app para Aplicativos.

Consultando release…Atualizações do aplicativo verificadas ao abrir.

Windows

Instalador de 64 bits em português, com atalho no menu Iniciar.

Consultando release…Atualizações assinadas recebidas pelo GitHub.

Android

APK para aparelhos ARM64. O Android pede autorização para instalar arquivos baixados.

Consultando release…Atualizações do painel chegam online. Para uma nova versão do APK, baixe o pacote e confirme a instalação.

iPhone

Adicione a versão web à Tela de Início enquanto a distribuição nativa pela Apple é preparada.

  1. Abra a central no Safari.
  2. Toque em Compartilhar.
  3. Escolha Adicionar à Tela de Início e Abrir como App, se disponível.
Abrir centralEsta opção é um app web instalado. Não é um IPA nem um aplicativo distribuído pela App Store.
